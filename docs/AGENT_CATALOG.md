# Agent Catalog

## Enterprise Super Agent

Routes requests, preserves a trace of routing scores, invokes the selected specialist, and writes an audit record.

## Sales Agent

**Tools:** accounts, contacts, opportunities, tickets, meetings  
**Use cases:** opportunity prioritization, stakeholder identification, account context, meeting preparation, next steps.

## Support Agent

**Tools:** tickets, accounts  
**Use cases:** SLA analysis, severity triage, escalation, customer-risk visibility.

## HR Agent

**Tools:** employees, knowledge  
**Use cases:** workforce summaries and HR policy Q&A. The lab intentionally avoids automating consequential employee decisions.

## Finance Agent

**Tools:** finance  
**Use cases:** budget/actual variance analysis and review thresholds.

## Operations Agent

**Tools:** inventory, shipments  
**Use cases:** stockout risk, supplier lead-time exposure, shipment delay escalation.

## Executive Agent

**Tools:** cross-functional read-only data  
**Use cases:** concise enterprise briefings and priority actions.

## Knowledge Agent

**Tools:** local knowledge base  
**Use cases:** policies, product information, operational playbooks, cited answers.
