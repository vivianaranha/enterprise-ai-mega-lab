# Contributing

Contributions are welcome. Keep additions aligned with the core goal: realistic enterprise AI patterns that can run without proprietary systems.

## Good contributions

- new specialist agents
- enterprise connectors or mock connectors
- new data domains
- additional guided labs
- evaluation cases
- security or governance controls
- alternative orchestration strategies
- optional local-model integrations

## Pull request checklist

- Keep default functionality local and deterministic.
- Do not commit secrets or real customer data.
- Add tests for new routes or tools.
- Document new environment variables.
- Update the agent catalog when adding an agent.
