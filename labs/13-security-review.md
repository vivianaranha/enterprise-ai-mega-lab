# Lab 13: Security Review

## Objective

Threat-model prompt injection, excessive permissions, data leakage, and unsafe writes in this architecture.

## Tasks

1. Run the baseline workflow.
2. Inspect the relevant agent, tool, API, and data path.
3. Make the change described in the objective.
4. Add or update an automated test.
5. Record what changed, what could fail, and what governance control is relevant.

## Evidence to capture

- API request and response
- code change
- test result
- architecture impact
- security/governance consideration

## Stretch challenge

Turn the deterministic behavior into a configurable strategy without breaking the local-first fallback.
